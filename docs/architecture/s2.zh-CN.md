## 1. 系统概览

### 1.1 框架身份（不变）

Synonz 是**显式、可控、可观测的 Agent 工程基础设施**（纯 Rust 库）。
四支柱（反过度抽象 / 行为可控 / 生命周期完备 / 内生可观测）与
High Level 优先原则（ADR-0010：80% 场景高层 API 解决，20% 原语自控）
共同构成一切设计的裁决标准。

### 1.2 分层结构（S2 时代）

```
┌───────────────────────────────────────────────────────────┐
│ 模式层     ReAct / Research / Reflection 预设（配方打包）      │ ADR-0010
├───────────────────────────────────────────────────────────┤
│ 组合层     Agent：无状态执行体（零环境知识）                    │
│           with_context(ctx) 挂叙事背景                        │
├───────────────────────────────────────────────────────────┤
│ 会话层     Conversation（真相实体）/ Turn / TurnInput           │ ADR-0011
├───────────────────────────────────────────────────────────┤
│ 背景层     Context：会话级 Runtime（叙事背景引擎）               │ ADR-0012
│           记忆句柄 + 主题状态 + 组装策略                        │
├───────────────────────────────────────────────────────────┤
│ 记忆层     Memory：主体拥有的分层记忆（L1/L2/L3）               │ ADR-0012
├───────────────────────────────────────────────────────────┤
│ 运行时层   SynonzRuntime（显式 Bootstrap）+ Subject（主体）     │ ADR-0012
├───────────────────────────────────────────────────────────┤
│ 原语层     Model / Tool / 事件流 / canonical Message           │ ADR-0003/0005/0006
├───────────────────────────────────────────────────────────┤
│ 适配层     synonz-openai / synonz-anthropic / synonz-mcp      │ ADR-0008
└───────────────────────────────────────────────────────────┘
```

依赖方向永远向下；**Agent 零环境知识**——环境链
`runtime → conversation → context` 全部由实体携带，随 TurnInput /
with_context 流入执行体。

|---|---|

## 2. 运行时与主体（ADR-0012；M11 待实施）

### 2.1 SynonzRuntime——进程级 Bootstrap

```rust
let runtime = SynonzRuntime::builder()
    // .register_conversation_store(...)   // 可选；缺省进程内默认
    // .register_memory(...)               // 可选；缺省进程内默认
    // .register_assembly(...)             // 可选；缺省 LayeredMemory
    .build();
```

- **显式构造，无隐式默认**：多实体隐式解析导致环境分裂（致命且无
  报错）；一致性由同源保证；
- **启动注册表 + 缺省默认实现**：未注册即用进程内默认；
- **工厂归属原则**：工厂方法合法当且仅当主语能完整决定产物的身份，
  否则应为挂载（`with_*`）。

### 2.2 Subject——主体（一等实体）

```rust
pub enum SubjectType {
    User,    // v1
    Agent,   // 变体自 v1 存在；交互记忆语义随 S3 落地
}

let subject = Subject::of(SubjectType::User, "user-42");
```

- **主体身份 = (SubjectType, id) 二元组**——记忆归属键；
- 记忆在交互中自动形成，**开发者永不创建 Memory 实体**；
- 会话创建强制携带主体。

## 4. 公共 API 全景

### 4.1 构建与预设（✅ 已实现）

```rust
Agent::react(model, tools)                       // ReAct 预设（零注入）
Agent::research(model, search_tools)             // 研究 prompt + 32 轮预算
Agent::reflection(model)                         // 草稿-批评-修订 prompt
Agent::builder().model(m).system_prompt(p)
    .tool(t).tools([...]).max_rounds(n).build()?
    .extend_system_prompt("追加指令")             // 组合扩展
    .with_timeout(d)                              // 默认预算
```

### 4.2 会话与输入（✅ S2a 已实现；工厂签名 M11 演进）

```rust
// v1 现行（S2a 落地）
let mut conv = Conversation::new();              // M11 起：new(&runtime, &subject)
let ti: TurnInput<'_> = conv.turn_input("北京？"); // 会话轮（&mut conv 串行化）
let ti: TurnInput<'static> = "1+1".into();        // 一次性糖

conv.id() / messages() / turns() / push_turn() / fork()
conv.truncate_last(n) / clear() / export() / import(bytes)

Turn { input, messages, output }                  // 公开只读
```

### 4.3 句柄家族（✅ M10 已实现）

| 入口 | 返回 | 主语义 | 第二面 |
|---|---|---|---|
| `agent.ask(ti)` | `Answer` | 流式：`next() -> ModelDelta` | `.await -> Result<AgentOutput>` |
| `agent.run(ti)` | `Run` | 结果：`.await -> Result<AgentOutput>` | 迭代 -> `AgentEvent` 全事件流 |

共同能力：`cancel()` / `with_timeout()` / drop = RAII 取消（四入口汇一
信号：cancel + drop + timeout + 外部 token）。

### 4.4 运行时与记忆（⏳ M11 待实施）

```rust
SynonzRuntime::builder().register_*(...).build()
Subject::of(SubjectType::User, "user-42")
Conversation::new(&runtime, &subject)? / of(&runtime, &subject, id)?
conv.context() -> Context                        // 会话产出叙事背景
agent.with_context(ctx)                          // 挂背景（返回 Agent）

// 三兄弟契约（同一注册模式）
trait ConversationStore { /* 会话真相存取 */ }
trait MemoryStore { /* l1/l2/l3: append/read/oldest/upsert/retrieve */ }
trait ContextAssembly { /* assemble(sources, input) -> Vec<Message> */ }
```

## 5. 记忆与上下文系统（ADR-0012；⏳ M11 待实施）

### 5.1 三概念边界

| 概念 | 本质 | 参与装配？ |
|---|---|---|
| Conversation | 对话真相（审计/回放权威） | **否** |
| Context | 会话级 Runtime（背景引擎） | 引擎 |
| Memory | 主体拥有的交互抽象 | **唯一来源**（L1/L2/L3 + input） |

### 5.2 分层记忆

| 层 | 作用域 | 内容 | 保底 |
|---|---|---|---|
| L1 | 当前会话 | 最近 N 轮原文 | `TurnCount(n)` |
| L2 | 当前会话 | 较早轮次摘要缓存 | `L2Overflow(n)`（蒸馏进 L3 非丢弃） |
| L3 | 跨会话（主体） | 长期知识（主题+溯源） | 检索预算 |

- 故障隔离：L3 不可用时 L1/L2 保证当前沟通不偏航；
- 串扰防护：跨会话经验必须经 L3 检索闸门；
- **片段三元组** `(subject_id, conversation_id, topic)` 唯一定位。

### 5.3 触发策略体系

- **强制保底**（确定性资源约束，不可移除只能叠加）：TurnCount /
  L2Overflow；
- **可叠加事件策略**：ConversationEnd（显式 end + 空闲超时兜底）、
  TopicShift、Demotion、Retrieval、Periodic、自定义；
- 主题机制：会话级状态机 + 片段继承；检测 = 首轮 + 每 K 轮（默认 3）
  + TopicShift 启用时逐轮；检测器可插拔（默认 LLM 轻量）。

### 5.4 组装策略与装配

| 实现 | 提供方 | 行为 |
|---|---|---|
| `LayeredMemory`（默认） | 框架 | L1+L2+L3+input 分层装配 |
| `ConversationHistory` | 框架 | 会话完整历史直发（v1 行为收编） |
| 自定义 | 开发者 | Low Level（策略只决定"发什么"） |

- **每次 ask 新鲜装配**（非 context() 时一次性）；
- 装配格式：`[System: system_prompt] [System: Memory recall] [L2 摘要]
  [L1 窗口] [User: input]`——人格与记忆注入分离可辨识；
- 装配期 LLM 调用以 `CallPurpose::ContextManagement` 出现在事件流
  （ADR-0003 设计的兑现）。

## 6. 一次交互的完整执行流（S2 目标形态）

```
Bootstrap   SynonzRuntime::builder().build()
主体         Subject::of(SubjectType::User, "user-42")
会话         Conversation::new(&runtime, &subject)
背景         conv.context()（经 runtime 解析主体记忆）
执行体       Agent::react(model, tools).build()?
              │ with_context(ctx)
              ▼
交互         agent.ask(conv.turn_input("..."))
              ├─ 装配（ContextAssembly：L1 窗口 + L2 摘要 + L3 检索
              │   + input；ContextManagement 事件可见）
              ├─ 执行（推理-行动-观察循环；事件流完整叙事）
              ├─ 落账（Completed → Turn 入 Conversation；Cancelled/
              │   Failed 不入史）
              ├─ 记忆写入（Turn → 主体 L1，带三元组）
              └─ 触发检查（保底 + 叠加策略 → 降级/晋升）
```

## 7. 横切语义

### 7.1 错误分层（不变 + S2 延续）

| 层级 | 类型 | 效果 |
|---|---|---|
| 工具级（软失败） | `ToolError` / `ToolResult::Err` | 喂回模型，run 继续 |
| run 级（硬失败） | `AgentError` | 终止事件；ask/run await 返回 Err |
| 取消 | `AgentError::Cancelled(CancelReason)` | 终止事件；非失败 |
| 落账 | 仅 Completed 入史 | Cancelled/Failed 历史停在轮前 |

### 7.2 可观测性

- 事件流是唯一信息通道（Answer 是 Run 的过滤视图）；
- `Requested` 事件携带装配产物（发给模型什么，回放可查）；
- `ContextManagement` purpose 标记装配期 LLM 调用（no-magic）；
- 记忆片段三元组 = 溯源（谁的记忆、哪场对话、什么主题）。

### 7.3 High/Low 双轨全景（S2 时代）

| 域 | High Level（80%） | Low Level（20%） |
|---|---|---|
| 模式 | 三预设开箱 | 原语自建循环 |
| 交互 | ask 流式 / run 结果 | 全事件流迭代 |
| 记忆时机 | 默认触发策略 | 自定义策略 / 显式流转 |
| 组装 | LayeredMemory 默认 | 自定义 ContextAssembly |
| 持久化 | 自动保存 | ConversationStore 显式操作 |
| 会话结束 | 空闲超时兜底 | 显式 conv.end() |

## 8. 扩展点与插件化（ADR-0009 + 0012）

| 扩展点 | 机制 | 注册 |
|---|---|---|
| 模型 | `impl Model` | Cargo 组合 |
| 工具 | `#[derive(Tool)]` / 动态 trait / MCP | builder |
| 模式预设 | 任意函数返回 AgentBuilder | 发布 crate |
| 会话存储 | `ConversationStore` 契约 | Runtime 注册表 |
| 记忆存取/检索 | `MemoryStore` 契约（检索逻辑在实现侧） | Runtime 注册表 |
| 组装策略 | `ContextAssembly` 契约 | Runtime 注册表 |
| 触发策略 | TriggerPolicy（叠加式） | 声明式配置 |

插件纪律：**编排在框架，存取在插件**；保底策略不可移除；
Embedder 永不进入框架（MemoryStore 实现的内部依赖）。

## 9. 术语表（S2 时代全量）

| 术语 | 定义 |
|---|---|
| Agent | 无状态执行体（程序）：模型+工具+prompt+预算的不可变组合；零环境知识 |
| Run / Answer | 执行句柄双面：全事件流 / 流式文本（同构：next + await + cancel） |
| Conversation | 对话真相实体：完整轮次记录；审计/回放权威；不参与装配 |
| Turn | 一轮问答记录 { input, messages, output }；仅 Completed 入史 |
| TurnInput | 参数对象：本轮输入 + 会话引用；ask/run 唯一参数模型 |
| Subject | 交互主体（一等实体）；身份 = (SubjectType, id)；记忆的归属者 |
| SynonzRuntime | 进程级 Bootstrap：显式构造、启动注册表、缺省默认实现 |
| Context | 会话级 Runtime（第三持续对象）：叙事背景引擎 |
| Memory | 主体拥有的交互抽象：L1（会话近轮）/ L2（会话摘要）/ L3（跨会话知识） |
| 片段三元组 | (subject_id, conversation_id, topic) 唯一定位 Memory 片段 |
| 装配 | 每次 ask 从记忆+input 构建发送视图（ContextAssembly 策略） |
| 触发策略 | 层间流转时机：保底（确定性资源约束）+ 叠加（事件驱动） |
| 双层 API | 事件流为核 + ask 流式壳（S1 语义，M10 演进为同构句柄） |
